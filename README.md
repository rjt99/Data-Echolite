# Data-Echolite

Data-Echolite is an AI-powered application that helps turn messy, unstructured data into clear insights and reports.

## What it does
- Ingests documents, text, images, and video content
- Uses multiple AI agents to parse, chunk, and extract useful information
- Connects related information across files to uncover patterns and relationships
- Detects conflicts, gaps, and important insights for easier decision-making

## Overview
The app is built for users who want to analyze large amounts of information quickly and transform it into structured, actionable intelligence.

## Tech stack
- Backend: Flask and Python
- Frontend: React with Vite
- AI processing: LLM-based agents and vector search
